# 🎬 RNN Movie Review Sentiment Analysis

A Deep Learning project that uses a **Bidirectional LSTM (RNN)** to classify movie reviews as **Positive** or **Negative**.

## 🧠 What I Used

- Python
- TensorFlow / Keras
- Pandas & NumPy
- Scikit-learn
- NLP & Text Preprocessing
- Tokenization & Padding
- Embedding Layer
- Bidirectional LSTM
- Dropout
- Early Stopping

## 📊 Dataset

The dataset contains **3,471 movie reviews** with two sentiment classes:

- Positive
- Negative

## ⚙️ Model

The text is cleaned, tokenized and padded before being passed through:

**Embedding → Bidirectional LSTM → Dropout → Bidirectional LSTM → Dense → Sigmoid**

The model is evaluated using **accuracy, precision, recall, F1-score and a confusion matrix**.

## 🚀 Goal

The goal of this project was to understand how **RNNs and LSTMs can be used for Natural Language Processing and sentiment analysis**.
